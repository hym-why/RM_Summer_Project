# S弯与PID实车调试记录

## 代码策略

最终模式使用两个RPR220数字输出形成偏差`-1/0/+1`。控制周期为10 ms，PID输出用于制造左右轮速度差。转向量越大，基础速度自动从`PID_LINE_BASE_SPEED`向`PID_LINE_MIN_SPEED`降低，避免在急弯仍以直线速度冲出黑线。

检测不到黑线时，程序执行以下恢复策略：

1. 清空PID历史状态，避免重新找到黑线时出现微分冲击。
2. 按最后一次有效偏差方向原地低速搜索。
3. 数码管显示`8`，蜂鸣器持续提示。
4. 重新检测到黑线后关闭蜂鸣器并恢复PID控制。

PID加入一阶微分滤波与抗积分饱和。`PID_DERIVATIVE_ALPHA`越大，微分越平滑，但响应也越慢。

## 调试前检查

1. 两个驱动轮架空，确认正速度时车辆应向前。
2. 白底与黑线上分别读取两路D0，确认黑线为高电平；相反时修改`LINE_BLACK_LEVEL`。
3. 调整探头高度和间距，使车身居中时两路均能稳定检测黑线。
4. 先在U形线路低速通过，再进入S弯。

## 推荐调参顺序

| 顺序 | 参数 | 调整方法 |
| --- | --- | --- |
| 1 | `PID_LINE_BASE_SPEED` | 从300-350开始，稳定后每次增加20 |
| 2 | `PID_KP` | 每次增加20，直到能及时纠偏但尚未持续摆动 |
| 3 | `PID_KD` | 从0.8开始每次调整0.1-0.2，用于压制左右摆动 |
| 4 | `PID_TURN_SLOWDOWN` | 急弯冲线时增加20；出弯太慢时减少20 |
| 5 | `PID_KI` | 默认保持0；只有长期稳定偏向一侧且机械无误时才少量加入 |

## 通过标准

- 按键后能启动，再次按键立即停止。
- U形线路连续运行三圈，不完全离开黑线。
- S弯连续运行三圈，不需要手扶复位。
- 丢线时数码管显示`8`并鸣叫，重新找到线后自动恢复。
- 连续运行期间主控不复位，L298N和电池不异常发热。
